# 知识库文档管理界面

2026-11-02 按确认的蓝白效果图调整。

- 主区为文档表格，提供名称搜索、全部/可用/处理中/失败筛选与真实数量。
- 右侧为文件、文件夹及拖放上传入口，保留自动识别和手动分块配置。
- 导入任务显示真实索引进度，所有进行中的任务始终可见；处理步骤按需展开。
- 下载、详情、知识图谱、重新分块、重新索引/重试位于每行的“…”菜单，文件删除恢复为行内按钮。
- 新建知识库恢复为名称输入和创建按钮，知识库删除恢复为直接按钮并沿用确认弹窗。
- 检索验证位于文档表格下方，来源核对沿用原有权限检查。
- 表格时间列为后端已有的 `created_at`（导入时间）；没有增加或伪造更新时间。
- 保留深色主题、窄屏布局；窄屏表格在卡片内部横向滚动，不撑宽整页。
