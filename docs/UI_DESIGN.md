# YugiTalk UI 设计方向 v3

日期：2026-10-10。状态：阶段 0 设计、阶段 1 React 工作台与阶段 2 登录门禁、空间选择及成员管理均已由用户验收。静态草图作为历史设计保留，实际入口为开发工作台 8080。

## 当前依据

视觉采用用户上传图片中的橙色外背景、黑色圆角主体、暖白文字、荧光绿按钮与紫/绿/橙/黄/蓝几何图标。布局按照用户要求采用类似 DeepSeek 的对话应用结构：Logo 左上角、选项左置、右侧独立视图。

Awwwards 分类中的案例是此前设计探索来源，用户新图片和后续布局要求是当前版本依据。

## 视觉规范

- 外背景：`#ff6b35`；内容背景：`#141414`；主文字：`#f8f5ec`。
- 行动按钮：`#c3ff68`，使用深色文字确保对比度。
- 功能图标：紫、绿、橙、黄、蓝底色配黑色形状；图标同时有文字说明。
- 大圆角用于外容器和输入框，小圆角用于侧栏入口；不使用整页品牌宣传主视觉。
- 默认浅色主题，暖纸色背景；可切换深色主题，两种主题均保留橙色外框和功能图标配色。
- 欢迎标题桌面 28px、手机 24px；正文和输入 16px、侧栏导航 14px、辅助文字 11–14px，以对话应用的阅读层级呈现。
- 手写代码注释为中文；草图没有外部字体、媒体或 CDN 依赖。

## 应用布局

1. 左上角 Logo，左侧新建对话、功能导航与最近会话。
2. 左下角任务详情、主题、设置及个人工作空间。
3. 右侧主区显示当前视图；对话视图默认展示欢迎语、输入框和任务灵感。
4. Agent、知识库、任务记录、设置切换到独立空状态视图，不向下串联多个页面。
5. 整体固定为一个视口高度，侧栏历史和内容区按需独立滚动。

## 已实现的草图交互

- 左侧导航切换独立视图，并以 URL hash 保留当前视图，刷新可恢复。
- 新建对话回到初始输入界面并清空输入；任务灵感只填入输入框，由用户继续编辑。
- 深浅主题切换；任务详情以独立抽屉打开。
- 抽屉背景 inert、焦点约束、Escape/遮罩关闭、触发按钮焦点恢复。
- 手机通过左侧折叠导航提供所有选项，收起导航后左上角仍有品牌标识。
- 发送保持禁用，不模拟真实 Agent 回答；空状态明确当前没有业务数据。

## 验证

三种视口（360/768/1440 px）、两种主题通过 axe 自动可访问性检查；Playwright 验证页面无整体横向或纵向溢出、导航切换、输入交互、Logo 位置和抽屉键盘操作。7 项浏览器测试全部通过，另人工检查桌面与手机截图。

最新测试证据见 [阶段 0 报告](./stages/00-design-and-probes.md) 和 `docs/stages/artifacts/ui-test-results.json`。本轮不修改后端，保留已执行的后端验证结果。
