# 阶段6评测资料

当前知识库可自行运行检索评测脚本，查看 Recall@5、Hit@5、完整证据命中率、耗时及逐题来源；配置、标注方法和指标口径见 [检索评测使用说明](./RETRIEVAL_EVALUATION.md)。

按评测结果调整候选数、上下文、父块、图谱、阈值及重排的顺序，以及参数所在文件、是否需要重建索引，见 [RAG 调优方案](./RAG_TUNING.md)。

2026-10-16 已将 MIRACL 中文训练集全部正负例段落导入独立知识库并完成 1,312 题检索基线，数据与计分口径见 [MIRACL 训练集说明](./MIRACL_TRAIN.md)，实际结果见 [评测报告](../../outputs/miracl-zh-train/README.md)。

2026-10-17 已固定训练集选定的参数，完成官方中文 dev 393 题的独立候选池验证：不重排 Recall@5 66.33%，本地重排 86.00%；排除与训练集问题文字相同的12题后，381题重排结果为85.89%。详见 [dev 验证报告](../../outputs/miracl-zh-dev/README.md)。本轮检索3786个已标注正负段落，不是493万段完整语料上的官方基准。

`stage6-corpus-v1.json`包含100份中文合成资料，每份10个标注问题。上传后记录运行环境中的文档ID，通过真实BGE-M3/Milvus搜索核对相关文档和答案片段，报告为 `../stages/artifacts/stage6-corpus-retrieval.json`。模板化合成资料便于复现，不能替代真实业务资料的泛化测试，也不评价生成答案正确率。

`stage6-quality-v1.json`固定60项质量用例：对话说明、带证据回答、证据缺失、指代歧义、不可信资料指令、只读工具各10项。文件包含预期事实、来源身份参考与逐例评阅标准；当前 `status=not_executed`、付费调用0，没有生成质量得分。不得把Mock回复或仅核对关键词视为真实模型质量通过。

实际评测须固定模型名称/版本、提示词、工具Schema、采样参数和输入上限，按独立账号/空间运行，保存模型请求ID、安全错误码、输出、真实来源ID和人工评分。来源的文件名/散列用于映射资料版本；服务端document_id/chunk_id在运行时生成，不能编造静态证据ID。跨空间权限和机密保护同时需要服务端测试，不能只看模型拒绝文本。

当前尚未获得真实模型评测授权，默认入口不会使用开发密钥调用付费服务。取得明确调用上限后再独立联调，记录费用/Token及超时，并按用例标准逐项复核。七步增强 RAG 已实现，路由、Grader、重写和 HITL 的自动工程验证已通过，人工验收待确认；真实模型评测仍独立保留，见 [实现与验收](../ENHANCED_RAG.md)。
