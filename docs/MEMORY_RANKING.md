# 候选记忆加权排序

`memory/context.py::build_messages` 在用户、空间及记忆开关校验后读取至多 20 条记忆。
`memory/ranking.py` 对候选逐条评分，再按得分降序尝试装入 2000 UTF-8 字节预算。
只保留完整条目，计入换行；放不下的条目跳过并记录 `byte_budget`，不会截断条件或否定。
单条记忆超过预算时也会省略。此次不增加相关性过滤阈值，排序不保证排除全部无关记忆。

## 分数与配置

```
R = clamp(cosine(query_embedding, memory_embedding), 0, 1)
I = (importance - 1) / 4
T = 2 ** (-max(age_days, 0) / half_life_days)
score = wR * R + wI * I + wT * T
```

- 问题取 `run.prompt`，至多前 2000 字符；截断状态记入追踪。
- 嵌入复用配置的 Embeddings 服务，每轮一次批量编码问题和已授权候选，至多 21 段。
  不引入新向量集合或缓存；实际部署需要已有嵌入服务可用。
- `importance` 由用户设置，整数 1～5，默认 3；不根据正文关键词或模型输出自动推断。
- 时间参考为任务创建时刻 `run.created_at`，记忆年龄依据 `Memory.created_at`。
  SQLite 无时区时间按 UTC 处理；普通编辑不会刷新创建时间。
- 同分先按相关性降序，再按 ID 升序，保证相同输入排序稳定。

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MEMORY_RANKING_WEIGHTS` | `[0.90,0.05,0.05]` | JSON 数组，依次为相关性、重要性、时间；非负、有限且和为 1 |
| `MEMORY_RECENCY_HALF_LIFE_DAYS` | `90` | 正数，时间分数的半衰期；本次预先固定，未据留出集调优 |
| `MEMORY_EMBEDDING_TIMEOUT_SECONDS` | `5` | 嵌入 HTTP 超时，1～30 秒，且不超过全局嵌入超时 |

嵌入请求失败时 R 统一置零，按重要性与时间继续排序，追踪标记
`memory_relevance_status=unavailable`。此时分数不与正常语义评分直接比较，不静默假装命中。
该 HTTP 超时沿用 httpx 的分阶段超时语义，不保证整个请求的严格墙钟时限。
禁用记忆后不查询候选或调用嵌入。

追踪 `memory_ranking` 包含 ID、各分项、总分、名次、是否选中与省略原因；不复制记忆正文。
最终偏好仍通过 `data_message("user_preferences", ...)` 作为用户级数据注入。
排名或重要程度不授予更高的系统权限，也不自动解决互相矛盾的记忆。
恢复已进入 Agent 图的任务沿用检查点消息，不重新评分或重复注入。

## 接口与数据库升级

`POST /api/v1/me/memories`、`PATCH /api/v1/memories/{id}` 支持 `importance`：

```json
{"content":"默认使用中文回答", "confirmed":true, "importance":5}
```

列表、创建及修改响应返回 `importance`。创建省略时为 3，修改省略时保留原值。
原有主动确认、敏感内容校验、用户隔离与记忆开关继续生效。
前端“个人记忆”提供等级选择，并在编辑时回显。

部署前运行 `backend` 目录下的 `.venv/Scripts/python.exe -m alembic upgrade head`。
新增迁移 `0027_memory_importance` 将旧记录回填为 3，并添加 1～5 的数据库约束。
本次未对现有业务数据库执行迁移，也未重启现有服务。

## 默认权重来源

实验脚本：`scripts/tune-memory-ranking.py`。
结果：[完整报告](../outputs/memory-ranking-tuning-20261113/REPORT.md)。

真实本地 BGE-M3 编码；64 个合成问题，每题 20 条候选。40 题调优、24 题按主题留出，
网格搜索 231 组权重。纯 NDCG 最优为 `(0.95,0,0.05)`；最终默认选
`(0.90,0.05,0.05)`，在调优 NDCG 下降约 0.0035 的情况下，必要记忆召回从 86.67% 升至 93.75%。
这一探索性取舍只依据调优集，完整保留第一阶段结果；不声称预注册或全局最优。

留出 NDCG@5 为 0.7723，预算内必要记忆召回率为 92.36%；仅相关性对照分别为 0.7302、70.83%。
未设过滤阈值，留出无关字节占比仍为 80.61%，故召回提高不代表上下文已精简。
标注由实现者提供，未独立复核；模板共享，候选文档并非完全隔离，不等同于真实用户泛化。
不测最终回答准确率，也未测生产嵌入延迟。真实数据和其他嵌入模型需要重新校准权重。
