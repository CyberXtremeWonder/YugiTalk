# 工作空间删除与页面调整

页面底部不再显示开发阶段。设置 → 工作空间提供“删除工作空间”，仅所有者可见；输入当前空间名称后确认。

删除区域提供个人空间下拉框，列出当前用户角色为所有者的全部可删除空间。可以选择当前空间以外的目标；切换目标清空名称确认输入，提交时使用所选空间ID，不会误删当前空间。普通成员或空间管理员参与的空间不列入删除选择。

删除采用软删除：隐藏空间、撤销所有成员关系、阻断读写访问，保留数据库业务记录、原文、向量和审计。不是磁盘空间清理功能，暂不提供恢复入口。空间内存在排队、运行、等待审批或等待澄清任务时返回冲突，请先停止或完成任务。删除最后一个空间后仍可创建新空间。

升级包含数据库迁移 `0014_workspace_deletion`。当前容器之前已停止，本轮不擅自重启。要加载新代码，在项目根目录先构建：

```powershell
docker compose build api frontend
```

再按 [启动与监控手册](./START_AND_MONITOR.md) 选择开发或公网演示启动方式，启动时迁移服务升级数据库。不要只重启旧镜像。

人工验收：创建测试空间 → 确认普通成员无删除权限 → 所有者输入名称删除 → 空间从列表消失 → 其他成员也不能再访问 → 其他空间仍正常。只使用专门测试空间，不删除真实资料所在空间。
