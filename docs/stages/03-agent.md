## 测试中发现并修复

1. 较矮窗口的侧栏把历史列表压成零高度，导致无法点击：保留历史区最小高度，侧栏允许滚动。
2. 新任务尚在提交时，停止按钮持有上一轮 Run：提交前清空旧运行，收到新 Run 后再显示停止按钮。
3. 模型退避重试缺少取消复核：每次重试与流片读取前检查取消／权限／截止时间。
4. Windows 验收进程沿用 cp950，中文结束输出报错：验收入口固定 UTF-8，重跑整套命令成功。
5. 快速失败可能先于页面连接事件流：加载会话时从最终 Run 恢复错误原因，补测低预算版本的 `token_budget_exhausted` 提示。

数据库升级前备份位于 `.cache/postgres-before-stage3.sql`，含本地业务数据，请仅在本机妥善保存。迁移当前为 0004_agent。开发数据卷保留；旧项目镜像仅在有标签／已记录且无容器引用时清理，未执行全局 prune。

## 你的人工验收步骤

1. 打开 http://127.0.0.1:8080，使用已有账号登录，选定工作空间。
2. 左边点 **Agent**，填写名称、系统提示词，勾选文本统计和报告排版，使用默认 30000 保守预算，点 **创建助手**。普通成员需要让该空间 owner／admin 创建助手。
3. 点 **新建对话**，选择助手，发送“请统计这段文本：你好世界”。应看到逐步回复、工具结果 JSON 代码块、任务完成，供应商标识为 mock，实际 Token 为未知。
4. 再发一个问题，确认多轮历史；从左侧历史打开同一会话。展开“管理对话”可改名或删除；执行中不能删除。任务记录可返回对应会话，详情显示真实状态与额度。
5. 发送较长文本并点 **停止生成**，应显示 cancelled；切换手机窗口检查输入区。刷新后仍可从历史读取消息。切换页面不会自动取消服务端任务。

## 真实模型配置与剩余限制

在根目录 `.env` 本地填写供应商、模型和密钥，**不要将密钥发到聊天**：

```dotenv
MODEL_PROVIDER=openai_compatible
MODEL_ID=供应商支持的模型标识
MODEL_BASE_URL=https://供应商实际域名/v1
MODEL_API_KEY=仅在本地填写
```

Anthropic 使用 `MODEL_PROVIDER=anthropic`，接口前缀包含 `/v1`，模型标识使用实际支持的值。适配器分别追加 `/chat/completions` 或 `/messages`，不要把完整方法路径重复写进前缀。

配置完成后执行 `docker compose up -d --force-recreate api worker`，在 Agent 页重新发布版本。先验证短中文流式回复、一次文本统计工具调用、多轮和取消；真实调用会产生供应商费用，联调采用低输出上限。记录供应商／模型／版本、延迟、真实用量与结果，不保存密钥或原始敏感输入。

当前预算是累计保守额度，不等于账单、不自动日重置。费用未配置价格版本，不能估算。只读工具不访问外网；RAG／引用／长期记忆属于阶段 4，写工具／审批／执行恢复属于阶段 5。

SSE 恢复读取不代表 Worker 宕机恢复。投递故障窗口、租约接管、事务 outbox、悬挂预算回收与检查点续跑待阶段 5；生产发布、安全加固与运维待阶段 6。当前不宣称正式可上线。
