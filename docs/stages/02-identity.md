## 人工验收

在 `E:\Code\YugiTalk` 操作。若服务未启动，先执行 `docker compose up --build -d --wait --wait-timeout 180`。

1. 创建自己的账号（邮箱和名称替换为你的信息）：

   ```powershell
   docker compose exec api python -m app.identity.bootstrap --email you@example.com --name "你的名字" --platform-admin
   ```

   输入并确认至少 12 位密码。页面没有默认密码；再次执行相同邮箱应拒绝覆盖。

2. 打开 [工作台](http://127.0.0.1:8080/)，先输入错误密码，确认提示、密码清空；再正确登录，刷新仍保持登录。
3. 确认默认浅色、Logo 左上角、导航左侧、字号和输入框点击行为保持已验收风格；切换深色，检查手机折叠菜单及详情抽屉。
4. 在“设置”创建空间；左上角切换到新空间，切换时草稿清空。空间 owner 可看到成员表单。
5. 用初始化命令添加第二个账号（省略 `--platform-admin`）。在第一个账号空间中添加该邮箱为普通成员，改为管理员，再移除。重复添加应失败。
6. 用第二个账号的独立浏览器会话登录：只能看到自己加入的空间，普通成员不能管理成员；被移除后再次请求该空间返回 404。平台管理员也不能直接查看未加入空间。
7. 点击退出登录，应回到登录页，刷新仍退出；开发者工具中 Cookie 为 HttpOnly／SameSite=Lax，开发 HTTP 无 Secure，生产 Secure 另有自动化验证。
8. 需要复核所有自动化检查时运行完整验收脚本。确认后回复 **“阶段 2 验收通过”**，再进入模型、Agent、流式响应与工具阶段。
